# FCGR 512

Esta carpeta contiene representaciones Frequency Chaos Game Representation (FCGR) generadas a partir de secuencias proteicas del VIH-1.

Las imágenes fueron creadas utilizando una resolución de 512 × 512 píxeles y se emplearon como entrada para el entrenamiento de la red neuronal convolucional (CNN).

## Contenido

- Imágenes FCGR generadas a partir de secuencias proteicas RT
- Representaciones utilizadas durante los experimentos de clasificación
- Archivos PNG empleados como entrada del modelo
