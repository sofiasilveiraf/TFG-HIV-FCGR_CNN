# Training

Scripts relacionados con el entrenamiento y análisis de la red neuronal convolucional (CNN) utilizada para la clasificación de representaciones FCGR del VIH-1.

## Contenido

- `train_cnn.py`  
  Entrenamiento principal de la arquitectura CNN utilizando las imágenes FCGR generadas previamente.

- `compare_runs_accuracy.py`  
  Comparación de métricas de accuracy entre diferentes ejecuciones y configuraciones del modelo.

## Objetivo

Estos scripts permiten entrenar, validar y analizar el rendimiento del modelo de aprendizaje profundo empleado en este trabajo para la clasificación de resistencia a fármacos antirretrovirales.
