# Split

Scripts utilizados para la división y organización de los conjuntos de datos empleados durante el entrenamiento y evaluación del modelo.

## Contenido

- `split_fcgr.py`  
  División de las imágenes FCGR en conjuntos de entrenamiento, validación y prueba.

- `make_index_fcgr_len.py`  
  Generación de índices y estructuras auxiliares para organizar las representaciones FCGR utilizadas durante los experimentos.

## Objetivo

Estos scripts permiten preparar los conjuntos de datos necesarios para garantizar una separación adecuada entre train, validation y test durante el proceso de entrenamiento de la CNN.
