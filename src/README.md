# Source Code

Esta carpeta contiene los scripts principales utilizados durante las distintas etapas del pipeline desarrollado en este trabajo.

## Estructura

- `preprocessing/`  
  Scripts de limpieza, filtrado y preparación de secuencias obtenidas de HIVDB.

- `fcgr/`  
  Generación y análisis de representaciones Frequency Chaos Game Representation (FCGR).

- `split/`  
  División de los conjuntos de datos en train, validation y test.

- `training/`  
  Entrenamiento y análisis de la red neuronal convolucional (CNN).

## Objetivo

Los scripts incluidos en este directorio implementan el flujo completo de procesamiento de datos y entrenamiento del modelo de aprendizaje profundo utilizado para la clasificación de resistencia a fármacos antirretrovirales del VIH-1.
