# FCGR

Scripts relacionados con la generación y análisis de representaciones Frequency Chaos Game Representation (FCGR) a partir de secuencias proteicas del VIH-1.

## Contenido

- `generate_fcgr_images.py`  
  Generación de imágenes FCGR a partir de secuencias proteicas procesadas.

- `compare_fcgrs.py`  
  Comparación y análisis visual de distintas representaciones FCGR generadas durante los experimentos.

## Objetivo

Estos scripts permiten transformar secuencias biológicas en representaciones espaciales basadas en FCGR, utilizadas posteriormente como entrada para el entrenamiento de modelos de aprendizaje profundo.
